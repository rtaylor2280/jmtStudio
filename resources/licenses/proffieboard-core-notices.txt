JMT plugin (Proffieboard Arduino core system library, patched; not ProffieOS)
=============================================================================

JMT Studio ships replacement builds of the Proffieboard Arduino core's system libraries
(libstm32l433.a, libstm32l452.a) carrying a fix for USB Mass Storage above 4 GiB. They are built
from the core's own sources, which carry the notices below, reproduced as their licences require.
